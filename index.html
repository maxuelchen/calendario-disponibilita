Configurazione Firebase richiesta

Apri questo file con un editor di testo e sostituisci i valori INCOLLA_QUI con quelli del tuo progetto Firebase. Le istruzioni complete sono nei commenti in cima al file HTML.

In breve:

  1. Crea un progetto su console.firebase.google.com
  2. Attiva Firestore Database (modalità production)
  3. Aggiungi una Web App e copia firebaseConfig
  4. Incolla i valori nello script in fondo al file
  5. Imposta le regole Firestore come descritto nei commenti
